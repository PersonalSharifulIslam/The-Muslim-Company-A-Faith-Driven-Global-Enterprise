==================================================
HOW THE SYSTEM SHOULD WORK
==================================================

Step 1:
Applicant submits job application.

Step 2:
System automatically generates a unique application reference number.

Step 3:
System saves all applicant information and status in the database.

Step 4:
Applicant receives:
- Success page
- Confirmation PDF
- Confirmation email
- Unique reference number

Step 5:
Applicant visits:
- /recruitment-status

Step 6:
Applicant enters the same reference number received after application submission.

Example:
BD/AI/10925/2026/X7K9P2

Step 7:
System searches the database using that exact reference number.

Step 8:
System automatically displays the matching applicant/application details and current recruitment status.
